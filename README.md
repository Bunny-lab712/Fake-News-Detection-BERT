# Fake News Detection in Online Media Using Deep Learning

A cutting-edge deep learning system built on the **BERT-base-uncased** framework to classify news articles into "Real" or "Fake" with **98.9% accuracy**.

## 🚀 Features
* **Bidirectional Contextual Understanding**: Utilizes Transformer self-attention mechanisms to analyze full sentence context simultaneously.
* **Dual Input Methods**: Supports direct text pasting or uploading documents (PDF/TXT).
* **Interactive Dashboard**: Built with a lightweight Gradio/Flask frontend for real-time verification and probability breakdown.

## 📊 System Performance
* **Accuracy**: 98.9%
* **Precision**: 98.7%
* **Recall**: 99.1%
* **F1-Score**: 0.989

## 🛠️ Tech Stack
* **Core NLP**: Python, PyTorch, Hugging Face Transformers (DistilBERT/BERT)
* **Data Processing**: Pandas, NumPy, Scikit-learn
* **Deployment/UI**: Gradio / Flask
